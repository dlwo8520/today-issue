## 실제 데이터

마지막 수집 스냅샷 291건에서 출처 미확인 포털 5건과 중복을 제외한 285건을 분석했습니다. 270개 그룹 중 적격 복수 출처 후보는 8개였고 최신순으로 검토하여 검증 통과 6개를 저장했습니다. 같은 사건이 카드 여러 개로 나뉘지 않도록 기존 그룹화와 원출처 제약을 유지했습니다.

GNews는 14개 날짜 구간의 첫 페이지와 최근 6개 구간의 두 번째 페이지를 수집합니다. NewsData는 최신 관련 기사 최대 6회로 보강하고, 이전 로컬 수집 이력을 2주 안에서 재사용합니다. NewsData latest 자체가 2주 전체를 제공하는 것은 아닙니다.

기본 시도 상한은 뉴스 API 26회(GNews 20·NewsData 6), GPT 18회입니다. 중복 입력은 캐시를 재사용하며 이번 마지막 추가 요약 실행은 신규 GPT 3회, 추정 $0.01347525를 기록했습니다. 앞선 개발까지 누적 OpenAI 추정은 $0.29679495입니다. 실패·수정 과정도 포함하며 청구서·뉴스 구독비·세금은 별도입니다. API 사용량과 비용 이력은 data/reports/history와 usage-total.json에 있습니다.
