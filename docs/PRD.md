## 구현 경계

화면은 저장된 JSON을 읽습니다. 입장 서버는 이메일과 쿠키를 확인합니다. 수집·그룹화·GPT 추출·요약·검토 구현은 Python 소스에 유지하되, 현재는 공통 정책으로 실행을 차단합니다.

검색·회원가입·회원 DB·개인화·광고·사용자 댓글·결제·관리자 대시보드·과거 에디션 아카이브는 현재 범위에 포함하지 않습니다. 이메일 입력 입장은 회원 계정이나 본인 인증을 제공하는 기능이 아닙니다.
