# 오늘의 잇슈 — MVP 제품 정의

## 사용자 문제와 가치

정보 과잉과 반복 보도로 주요 사건의 맥락을 이해하기 어렵습니다. 같은 사건의 여러 출처를 묶고 쉬운 제목·설명·원문 링크를 제공합니다. “하루를 이해하는 5분”은 제품 목표이며 사용자 실험 결과가 아닙니다.

## 현재 범위

최근 2주(336시간) 안의 복수 출처 사건을 최신 기사 발행 시각 순으로 검증해 최대 6개를 표시합니다. PC 3열·태블릿 2열·모바일 1열, 공유 가능한 hash 상세 URL, 첫 원문 사진, 상세 이동 목록, 원문 링크, 선택적인 용어·반응과 주장 주체 표시를 제공합니다. 문장별 번호와 선정 설명은 사용자 요청으로 제거하고 내부 근거 검증은 유지합니다.

Python은 GNews·NewsData 수집과 기간 내 이력, 정규화·중복 정리·사건 그룹화·최신순 선정, GPT 근거 추출→요약→검토, 코드 검증·원자적 저장을 담당합니다. DEMO는 키 없이 실행합니다. 실제 API와 로컬 비공개 Live는 검증했습니다.

검색·로그인·회원가입·개인화·광고·사용자 댓글·결제·관리자 대시보드·DB·과거 에디션 아카이브는 MVP에서 제외합니다.

## 기술·운영

React·TypeScript·Vite·Tailwind, Python·Pydantic·httpx·feedparser·OpenAI SDK를 사용합니다. 그룹화는 CPU에서 실행 가능한 문자 TF-IDF와 사건·시간 제약을 사용합니다. 정적 JSON·hash 경로로 상시 백엔드 없이 실행합니다.

GitHub Actions CI와 선택적 Pages·KST 오전 7시 예약·상태 복원 구성이 있습니다. ENABLE_PAGES=true일 때 발행을 활성화합니다. 공개 Live는 실제 가입 플랜과 AI 전송·보관·요약·사진 사용 범위를 확인한 뒤 운영합니다. RSS는 유지하지만 권한 미확인 상태로 기본 비활성입니다.

## 품질 기준과 완료 상태

가짜 기사로 수를 채우지 않고 관측 관심도 결측을 0으로 바꾸지 않습니다. 알려진 공동 원출처를 독립 근거로 중복 계산하지 않습니다. 자동 검토를 완전한 사실 확인으로 설명하지 않습니다. 기능 완료는 실제 실행과 검증을 근거로 기록하고 로컬 검증·소스 업로드·공개 운영을 구분합니다.

현재 기능·118개 테스트·제약·남은 운영 항목은 [전체 1차 개발 정리](PHASE_1_REPORT.md)에 있습니다.
