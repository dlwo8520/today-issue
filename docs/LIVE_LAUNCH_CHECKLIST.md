## 뉴스와 사진 이용 범위

- [ ] GNews·NewsData 각 계정의 가입 플랜과 일일 quota·속도·제공 기간 확인
- [ ] 제공 텍스트의 OpenAI 전송·보관·캐시 사용 허용 범위 확인
- [ ] 제목·출처 메타데이터·생성 요약의 공개 표시 범위 확인
- [ ] 원문 사진 URL 표시와 필요한 출처 표시·보관 조건 확인
- [ ] 유료 archive가 필요하면 권한·요금·실제 제공 기간 확인
- [ ] 확인 근거와 날짜를 config/news_apis.json의 permission_reference 등으로 기록
- [ ] 실제 허가를 확인한 뒤에만 usage_scope와 public_reuse_granted 변경

읽을 수 있는 URL이나 API 인증 성공은 공개 재사용 허가가 아닙니다. 현재 GNews는 날짜 구간과 제한된 페이지, NewsData는 latest의 최근 48시간, 나머지는 기간 내 로컬 수집 이력을 사용합니다. 2주 전체 기사나 유료 archive를 확보한다고 가정하지 않습니다.

RSS는 --collector rss로 유지하지만 모든 소스는 기본 비활성입니다. RSS를 추가로 사용하면 config/sources.json의 reuseGranted·llmProcessingGranted·permissionReference·reviewedAt를 실제 허가에 맞게 설정합니다. 같은 통신사의 재게시를 독립 원출처로 중복 계산하지 않습니다. [출처 기록](SOURCES.md)

## OpenAI·예산·키 운영

- [ ] 실제 계정의 Responses·Structured Outputs 모델 접근과 프로젝트 권한 확인
- [ ] 결제/크레딧·호출/토큰 제한·월간 예산·지출 알림 확인
- [ ] 실제 차단이 필요하면 알림과 별도로 계정 한도와 파이프라인 시도 상한 설정
- [ ] 뉴스 26회·GPT 18회 기본 상한을 실제 quota에 맞춰 조정
- [ ] 모델별 관측 토큰·요율·실패 비용을 기록하고 정상 하루 비용 산정
- [ ] 키 교체·분실 대응·Secrets 관리 담당과 절차 지정

현재 로컬 모델은 gpt-5.4-mini이며 OPENAI_MODEL로 선택합니다. 정상 이슈 하나는 추출·요약·검토 3회입니다. 실패도 18회 예산 안에 포함되며 무한 재시도하지 않습니다. 개발 누적 추정 $0.29679495는 실패·평가·수정을 포함하므로 일일 운영 단가가 아닙니다. 뉴스 구독비·세금·환율은 별도입니다.

키 변수는 GNEWS_API_KEY·NEWSDATA_API_KEY·OPENAI_API_KEY입니다. .env는 Git과 전달 ZIP에서 제외하며 VITE_ 접두사를 붙이지 않습니다. 현재 .env를 예시 파일로 덮어쓰지 않습니다. [API 실행 안내](API_LIVE_INTEGRATION.md)

- [ ] 근거 없는 배경·원인·반응을 추가하지 않는지 확인
