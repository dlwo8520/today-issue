## 변경 작업을 할 때

| 작업 | 확인할 것 |
|---|---|
| 문서 수정 | 실행 방법·링크·현재 운영 상태가 일치하는지 확인 |
| 화면 수정 | 기존 JSON과 수집 시각 보존, 홈·상세·모바일 확인 |
| 개인용 재배포 | 이메일 입장 서버·경로 설정과 기존 보호 구성 유지 |
| 소스 전달 | 키·실제 뉴스·캐시·Live 캡처 제외 |
| 데이터 이상 발견 | 원문과 저장된 근거 대조 후 수정 범위를 정함 |

뉴스 자동 갱신이나 공개 서비스 확장은 현재 고정 운영 범위에 포함하지 않습니다. 사용자가 재개를 요청하면 데이터 이용 범위·생성 설정·갱신 경로를 별도로 검토합니다.
