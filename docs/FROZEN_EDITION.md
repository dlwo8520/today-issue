## 중지된 것

| 경로 | 현재 동작 |
|---|---|
| GPT·뉴스·RSS 수집 | 공통 정책으로 차단 |
| Live CLI의 모든 단계 | API 호출과 파일 변경 없이 종료 |
| `--fresh`·`--from-cache`·`--dry-run` | 중지 정책을 우회하지 못함 |
| 실행 함수·어댑터·GPT 요약기 직접 호출 | 정책 확인 후 차단 |
| GitHub 예약·수동 실행 | 해당 트리거 제거 |
| GitHub의 생성·배포 작업 | 제거; 소스 검사만 유지 |

기준 정책은 `config/service.json`의 **`updates_enabled=false`**입니다. 정책이 없거나 잘못된 경우에도 호출을 허용하지 않습니다.

기존 `.env`와 API 키는 소스에서 제외한 채 유지합니다. 이 프로젝트의 호출을 중지한 것이며, 키 자체를 폐기하거나 다른 프로젝트의 사용 설정을 변경한 것은 아닙니다.
